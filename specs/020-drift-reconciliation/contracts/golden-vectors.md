# Contract: Golden Vectors

Both platforms MUST reproduce these fixtures exactly. Generated by `web/scripts/gen-vectors.ts` (`cd web && npm run gen:vectors`); asserted by web `*.parity.test.ts` (local) and iOS `*ParityTests.swift` (CI). New files need a `project.pbxproj` Copy-Bundle-Resources + test-target entry.

## New vectors

### currency-names.json — `CURRENCY_NAMES` (TS) ≡ `Currency.displayName` (Swift)
- Keys: all 7 currency codes. Values: canonical display names.
- Canonical: iOS enum, **except GBP → "UK Pound"** (both sides adopt it).
- Web test: `web/test/currency-names.parity.test.ts`. iOS: `CurrencyNameParityTests.swift`.

### currency-symbols.json — fixed symbol table (no locale derivation)
- Keys: all 7 codes. Values: fixed glyphs; `cny` = `CN¥` (canonical), disambiguated from `jpy ¥`.
- Both platforms return these from a hardcoded table (iOS stops deriving from `NumberFormatter`).
- Web test: `web/test/currency-symbols.parity.test.ts`. iOS: `CurrencySymbolParityTests.swift`.

### lease.json — `web/components/housing/lease.ts` ≡ iOS `LeaseInfo.swift`
- Array of `{ input, expected }`. Deterministic `asOf` injected; generation pins `TZ=UTC`, the TZ-sensitive web assertion pins `TZ=America/New_York`.
- Covers: `rentDueDay`; `daysUntilNextRent` incl. **due-day > days-in-month clamp** (the iOS off-by-one) and "Due today" (0); `daysUntilEnd`; `isRenewalSoon`.
- Web test: `web/test/lease.parity.test.ts`. iOS: `LeaseParityTests.swift`.

## Changed vector (intentional)

### transaction-filters.json — add cases
- A query with a trailing newline → trims to inactive (both platforms).
- A mixed-case source set → `availableSources` localized case-insensitive order.
- All existing cases unchanged. iOS `TransactionFilters.swift` aligned first, then regen.

## Unchanged vectors (MUST stay byte-identical)

- `housing-net-rental.json` — occupancy becomes an explicit column but the pure net functions and their `{rentCents, occupied}` inputs are unchanged (mapping-layer swap only).
- `currency.json`, `transaction-splits.json`, `insights.json`, `mortgage.json`, `member-balance.json`, `dashboard-month-scope.json` — no engine change reaches their asserted values. `git diff shared/test-vectors/` after `gen:vectors` MUST show only: the 3 new files + the `transaction-filters.json` additions. Anything else is unintended drift → STOP.

## Behaviors pinned by per-platform parity unit tests (not vectors)

Display-string / exception behaviors that don't fit the value-equality vector shape, each asserted identically on web and iOS:
- money negative sign (U+2212), leading `+` only when amount > 0, `toUSDCents` guard on rate ≤ 0.
- insights money always 2 decimals.
- `sharePercent` round-half-away-from-zero on negative half-values.
- `monthBounds` rejects non-`yyyy-MM` strings (throws) on both platforms.
