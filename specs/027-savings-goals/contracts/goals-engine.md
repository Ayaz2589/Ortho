# Contract: Goals pure engine (`web/lib/finance/goals.ts`)

Pure, deterministic, side-effect-free. Integer USD cents in and out. Reference
"today" is injected. Pinned by `shared/test-vectors/goals.json` +
`web/test/goals.parity.test.ts`; hand-derived correctness in
`web/test/goals.unit.test.ts`. Generated by `web/scripts/gen-vectors.ts`.

## Thresholds — `web/lib/finance/goals-thresholds.ts`

```ts
export const GOAL_THRESHOLDS = {
  /** Rule: goal off-track. Must be behind steady-pace expectation by at least this
   *  fraction of the target to flag (avoids noise when only marginally behind). */
  offTrackToleranceFraction: 0.05,
  /** Days per month used to size the suggested monthly contribution. */
  daysPerMonth: 30,
} as const
```

## Calendar-day index (timezone-stable)

```
dayIndex(d) = Math.floor(Date.UTC(d.getFullYear(), d.getMonth(), d.getDate()) / 86_400_000)
```

Built from **local** getters (the `insights.ts` rule); `target_date` (`'YYYY-MM-DD'`)
is parsed with `parseLocalDate` before indexing. TZ=UTC-pinned in the harness.

## `goalProgress(targetCents, contributions) → GoalProgress`

- `saved = Σ contributions.amount_cents` (exact integer sum).
- `remaining = max(0, targetCents − saved)`.
- `fraction = targetCents > 0 ? clamp(saved / targetCents, 0, 1) : 0`.
- `reached = targetCents > 0 && saved >= targetCents`.
- Never negative remaining, never fraction > 1 (FR-005/FR-006).

## `goalPacing(targetCents, targetDate, startISO, savedCents, now) → GoalPacing`

Let `startIdx = dayIndex(new Date(startISO))`, `nowIdx = dayIndex(now)`,
`targetIdx = dayIndex(parseLocalDate(targetDate))`.

- **No `targetDate`** → `{ off_track:false, past_due:false, expected_cents:0,
  shortfall_cents:0, suggested_monthly_cents:0 }`.
- `span = targetIdx − startIdx`, `elapsed = nowIdx − startIdx`.
- `expectedFraction = span <= 0 ? 1 : clamp(elapsed / span, 0, 1)`.
- `expected_cents = round(targetCents × expectedFraction)`.
- `past_due = nowIdx >= targetIdx`.
- `reached = savedCents >= targetCents` (targetCents > 0).
- `remaining = max(0, targetCents − savedCents)`.
- `shortfall_cents = max(0, expected_cents − savedCents)`.
- `daysLeft = targetIdx − nowIdx`; `monthsLeft = daysLeft <= 0 ? 0 :
  max(1, ceil(daysLeft / daysPerMonth))`.
- `suggested_monthly_cents = reached ? 0 : (monthsLeft <= 0 ? remaining :
  ceil(remaining / monthsLeft))`.
- **`off_track`**:
  - `false` if reached.
  - `true` if `past_due` (out of time, not reached) — FR-010.
  - else `true` iff `shortfall_cents >= max(1, round(targetCents ×
    offTrackToleranceFraction))`.

## `goalOffTrackInsight(goal, contributions, now, tr, locale) → Insight | null`

Returns `null` unless `goalPacing(...).off_track` (and target > 0). Otherwise:

| Field | Value |
|---|---|
| `id` | `goal-offtrack-${goal.id}` (lowercase, stable — part of the contract) |
| `severity` | `'warning'` (calm; **never `critical`/red** — behind is never red, Constitution I/II) |
| `icon` | `'target'` (add to the `InsightsCardStack` icon map) |
| `category` | `goal.linked_category ?? null` |
| `magnitude_cents` | `shortfall_cents` (how far behind — drives sort order) |
| `title` / `body` | localized via `tr` — **not** vectored (display strings, per `docs/shared.md`) |

Body conveys: saved of target, ~amount behind, and the **suggested monthly
contribution** to still reach the target by the (locale-formatted) date (FR-008).

## `goalInsights(goals, contributionsByGoalId, now, tr, locale) → Insight[]`

Maps each goal → `goalOffTrackInsight`, drops `null`, sorts by the exported
`compareInsights` (severity asc, magnitude desc). Not sliced (the caller merges with
`generateInsights` output and slices to the display limit).

## `compareInsights(a, b)` — exported from `web/lib/finance/insights.ts`

Refactor of the existing inline sort (severity order `critical<warning<info<positive`,
tie-break `magnitude_cents` desc). **No behavior change** to `generateInsights` /
`insights.json`; only extracted so the merge in the two insight consumers sorts
goal + base insights consistently.

## Vector file — `shared/test-vectors/goals.json`

Shape: `{ progress: [{name, input, expected}], pacing: [{name, input, expected}] }`.
`input` carries integer cents + ISO date-only/`created_at` strings + an injected
`now`; `expected` carries the full `GoalProgress` / `GoalPacing` numeric object.
Cases (≥ the SC-002/SC-003 matrix):

**progress**: empty (0/target), single contribution, multiple summing under target,
exactly reached, over-funded (remaining floored, fraction capped), debt-payoff
(identical math), non-positive-target guard (fraction 0).

**pacing**: no date (all-zero, on-track); on-pace (saved ≥ expected); behind beyond
tolerance (off-track, with expected/shortfall/suggested); marginally behind within
tolerance (on-track); reached regardless of date (on-track); past-due not reached
(off-track, suggested = remaining); span ≤ 0 / due-now (reached ⇒ on, else off);
mid-pace rounding case (odd target × fraction).
