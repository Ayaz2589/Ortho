# Contract: Rollover math (`computeRolloverLedger`)

The pure, **golden-vector-locked** recurrence. Fixtures:
`shared/test-vectors/budget-rollover.json` (generated by `gen-vectors.ts`,
asserted by `web/test/budget-rollover.parity.test.ts`). Integer USD cents
everywhere; no rounding (only +, −, min, max).

## Signature

```
computeRolloverLedger(
  { type, baseLimitCents, rolloverCapCents, openingCarryCents = 0 },
  monthlySpendCents: number[]
) -> RolloverMonth[]   // one entry per input month, in order
```

## Per-month recurrence

For month index `m` with spend `s = monthlySpendCents[m]`:

```
carriedIn = type === 'fixed'
              ? 0
              : (m === 0 ? openingCarryCents : ledger[m-1].carriedOut)
effectiveLimit = baseLimitCents + carriedIn
remaining      = effectiveLimit - s
carriedOut     = type === 'fixed'       ? 0
               : type === 'flex'        ? clampCap(max(0, remaining))
               : /* non_monthly */        remaining
```

`clampCap(x) = rolloverCapCents == null ? x : min(x, rolloverCapCents)`.

## Invariants (asserted by the parity test)

- `effectiveLimitCents === baseLimitCents + carriedInCents` for every month.
- `remainingCents === effectiveLimitCents - spentCents` for every month.
- `fixed` ⇒ `carriedInCents === 0 && carriedOutCents === 0 &&
  effectiveLimitCents === baseLimitCents` for every month.
- `flex` ⇒ `carriedOutCents >= 0` and, when capped,
  `carriedOutCents <= rolloverCapCents`.
- `non_monthly` ⇒ `carriedOutCents === remainingCents` (signed, uncapped).
- All outputs are integers.

## Vector scenarios (must include)

1. **fixed, three months** — carriedIn/Out all 0; remaining = base − spent each
   month (regression that fixed == today).
2. **flex, surplus accumulates** — base 60000; spends [50000, 40000, 55000] →
   carriedIn [0, 10000, 30000]; remaining [10000, 30000, 35000].
3. **flex, overspend is forgiven** — base 60000; spends [50000, 75000, 50000] →
   carriedIn [0, 10000, 0] (month-2 overage does not become month-3 debt);
   remaining [10000, −5000, 10000]; carriedOut [10000, 0, 10000].
4. **flex, capped** — base 60000, cap 15000; spends [40000, 40000, 40000] →
   carriedOut clamped to 15000 each surplus month; carriedIn [0, 15000, 15000].
5. **flex, opening carry** — openingCarry 20000; base 60000; spends [10000] →
   carriedIn 20000; effective 80000; remaining 70000; carriedOut clamp(70000).
6. **non_monthly, sinking fund builds then draws down** — base 5000; spends
   [0, 0, 0, 0, 0, 60000] → carriedIn [0,5000,10000,15000,20000,25000];
   month-6 remaining = 5000 + 25000 − 60000 = −30000; carriedOut −30000
   (signed debt carries).
7. **non_monthly, recovers from negative** — continue: base 5000, opening −30000,
   spend [0, 0] → carriedIn [−30000, −25000]; remaining [−25000, −20000].
8. **zero base** — base 0, any type → effective = carriedIn; documents the
   disabled-bucket edge (card/insight hide it separately).
9. **single month** — length-1 array for each type (boundary).
10. **empty spend array** — returns `[]`.
